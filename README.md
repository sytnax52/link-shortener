# Link Shortener

A full-stack URL shortener application built with the MERN stack.

## Features

- Create short URLs
- Redirect to original URL
- Copy shortened links
- Recent links list
- Click counter
- Responsive UI

## Tech Stack

- React
- Vite
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- Mongoose
- Axios

## Installation

### Backend

```bash
cd server
npm install
npm run dev
```

### Frontend

```bash
cd client
npm install
npm run dev
```
